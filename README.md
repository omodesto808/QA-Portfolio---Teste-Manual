# **Projeto de QA — Testes Manuais em E-commerce**

## **1\. Sobre o projeto**

Este projeto apresenta um ciclo completo de testes manuais aplicado a uma aplicação de e-commerce, desenvolvido como parte do meu portfólio de QA.

O objetivo é demonstrar a aplicação prática de conceitos de Quality Assurance, desde o planejamento e exploração da aplicação até a elaboração, execução e análise dos testes, incluindo a identificação e documentação de defeitos.

## 2. Navegação

A documentação está organizada de acordo com a ordem do ciclo de testes

| *Documento* | Conteúdo |
| :---- | :---- |
| 01- Plano de teste | Planejamento, escopo, estratégia, ambiente e critérios de teste  |
| 02- Log de teste exploratório | Documentação do processo de exploração e elaboração dos casos de teste  
| 03- Casos de teste | 25 casos de teste detalhados, com pré-condições, dados de teste, passos, resultado esperado, prioridade e tipo de teste.  |
| 04- Relatório de execução | Matriz de execução, resultados e evidências  |
| 05- Relatório de bugs | Documentação detalhada dos defeitos identificados  |
| 06- Relatório de resumo dos testes | Consolidação e análise dos resultados do ciclo  |
